## About The Project

<p align="center">
  <img src="images/cyberdeck.png" alt="3D Printed CyberDeck" width="600" height="600">
</p>

The **CyberDeckV.01** is a unique, customizable Raspberry Pi cyberdeck built using 3D-printed components. Designed for portability and functionality, this project empowers you to create your own mobile computing station, all powered by the versatile Raspberry Pi.

### Features:
- Fully customizable 3D-printed case
- Compact, portable design
- Ideal for Raspberry Pi 4 or Raspberry Pi 3
- Support for 3.5-inch mini screen
- Optional foldable keyboard + mouse combo for added flexibility

## Getting Started

Follow these instructions to set up your CyberDeck.

### Items You Will Need:
- **x2 - M4*20 screws**
- **x2 - M4 Nuts**
- **Plastic Glue**
- **Raspberry Pi 4/3**
- **3.5-inch Mini Screen for Raspberry Pi**
- *(Optional)* Foldable keyboard + mouse combo

---

### 3D Printer Settings:
Use the following settings for the best print quality:
- **Layer Resolution**: 0.2 mm
- **Infill**: 100% (for optimal strength)

---

### Assembly Instructions:
1. **Download STL files** from the link below:
   - [Download STL Files](https://cults3d.com/en/3d-model/gadget/cyberdeck-m1g4eli7us-v1-miguelitus)
2. **Print the parts** using your preferred 3D printer.
3. **Glue the 5 main pieces** together using plastic glue.
4. **Install the Raspberry Pi and the mini screen** into the 3D-printed case.
5. **Configure the Raspberry Pi** with your preferred software and setup.

For detailed software setup and programming instructions, refer to the project's documentation.
